# json-invalid-syntax

检测 JSON 文件是否存在语法错误。

## 严重程度

`critical`

## 说明

JSON 是一种严格的序列化格式，任何语法错误都会导致解析失败，进而影响构建、配置加载或运行时行为。本规则使用 `JSON.parse()` 检测文件是否合法，并尝试定位错误位置。

## 常见问题

- 键名或字符串未使用双引号包裹
- 对象/数组末尾多余的逗号
- 缺少逗号分隔符
- 转义字符错误

## 示例

### 错误

```json
{
  "name": "app"
  "version": "1.0"
}
```

### 正确

```json
{
  "name": "app",
  "version": "1.0"
}
```

## 修复建议

1. 使用支持 JSON 校验的编辑器查看错误位置。
2. 优先使用 JSON 模式或 schema 进行校验。
3. 对于配置文件，可考虑改用 YAML 以减少语法陷阱。
