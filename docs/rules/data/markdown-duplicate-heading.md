# markdown-duplicate-heading

检测 Markdown 文件中是否存在同层级重复的标题。

## 严重程度

`suggestion`

## 说明

重复的标题会降低文档可读性，并可能导致基于锚点的链接或目录生成冲突。本规则按 H1–H6 层级分别检测，同一层级内出现相同标题文本时报告；不同层级允许使用相同文本。

## 示例

### 错误

```markdown
## 安装

...

## 安装
```

### 正确

```markdown
# 安装

...

## 安装
```

```markdown
## 安装

...

## 卸载
```

## 修复建议

1. 合并重复的标题内容。
2. 使用更具体的标题文本区分不同章节。
3. 如果是自动生成的片段，建议调整生成逻辑或忽略该文件。
