# json-duplicate-key

检测同一层级 JSON 对象中是否存在重复键。

## 严重程度

`warning`

## 说明

JSON 标准未明确禁止重复键，但大多数解析器只会保留最后一个值。重复键容易导致配置被意外覆盖，产生难以排查的行为。本规则先验证 JSON 语法合法，再遍历对象映射，报告同一层级中的重复键。

## 示例

### 错误

```json
{
  "name": "app",
  "name": "dashboard"
}
```

### 正确

```json
{
  "name": "app",
  "displayName": "dashboard"
}
```

## 修复建议

1. 合并语义相同的键。
2. 如果确实需要保留多个值，请改用数组结构。
3. 不同层级的对象允许使用相同键名，本规则不会跨层级误报。
