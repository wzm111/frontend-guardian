# markdown-empty-link

检测 Markdown 中链接目标为空的链接。

## 严重程度

`warning`

## 说明

`[文本]()` 这种空链接在渲染时不会产生有效的跳转目标，通常意味着链接被意外清空或遗漏。本规则会标记所有空链接目标，提醒作者补充正确的 URL 或移除链接。

## 示例

### 错误

```markdown
# 文档

详情请见 [API 文档]()。
```

### 正确

```markdown
# 文档

详情请见 [API 文档](https://example.com/api)。
```

## 修复建议

1. 补充正确的目标 URL。
2. 如果不需要跳转，请移除方括号后的链接语法，仅保留纯文本。
