# 可访问性规则 (Accessibility / A11y)

参考 [WCAG 2.1](https://www.w3.org/WAI/WCAG21/quickref/) 标准和 [WAI-ARIA](https://www.w3.org/WAI/ARIA/) 规范。

## 🔴 Critical

### A001 — 图片必须有 alt 属性
- **说明**: `<img>` 标签必须包含 `alt` 属性
- **例外**: 装饰性图片可设置 `alt=""`（空字符串），表示辅助技术可忽略
- **示例**:
```jsx
// ❌ 错误
<img src="logo.png" />

// ✅ 正确
<img src="logo.png" alt="公司 Logo" />
<img src="decoration.png" alt="" />
```

### A002 — 表单元素必须有 label
- **说明**: input、select、textarea 必须关联 label 或通过 aria-label 说明
- **示例**:
```jsx
// ❌ 错误
<input type="text" placeholder="请输入用户名" />

// ✅ 正确: 显式关联
<label htmlFor="username">用户名</label>
<input id="username" type="text" />

// ✅ 正确: 隐式包裹
<label>
  用户名
  <input type="text" />
</label>

// ✅ 正确: aria-label
<input type="text" aria-label="用户名" />
```

### A003 — 按钮必须是语义化标签
- **说明**: 可点击元素必须使用 `<button>`，禁止用 `div/span` + onClick 模拟按钮
- **原因**: div/span 无法通过键盘触发、无法被屏幕阅读器识别为交互元素
- **示例**:
```jsx
// ❌ 错误
<div onClick={handleClick}>提交</div>

// ✅ 正确
<button onClick={handleClick}>提交</button>
```

### A004 — 焦点管理
- **说明**: 
  - 弹窗/模态框打开时，焦点应移动到弹窗内部
  - 弹窗关闭时，焦点应回到触发元素
  - 使用 `tabIndex={-1}` 使非交互元素可聚焦（仅用于 JS 控制的焦点）

## 🟡 Warning

### A005 — ARIA 属性合法性
- **说明**: 使用正确的 ARIA 角色和属性
- **常见错误**:
  - `role="button"` 但没有 `tabIndex={0}`
  - `aria-hidden="true"` 但包含可聚焦元素
  - 无效的 ARIA 属性值

### A006 — 颜色对比度
- **说明**: 文本与背景色的对比度应满足 WCAG AA 标准
  - 正文文字：≥ 4.5:1
  - 大号文字（18pt+ 或 14pt+ 粗体）：≥ 3:1
- **工具**: [WebAIM Contrast Checker](https://webaim.org/resources/contrastchecker/)

### A007 — 键盘导航
- **说明**: 所有交互元素应可通过键盘操作
  - Tab 顺序符合视觉顺序
  - 提供可见的焦点指示器（focus ring）
  - 自定义组件需处理 Enter/Space 键

### A008 — 语义化 HTML
- **说明**: 使用正确的 HTML5 语义标签
  - 页面结构：`<header>`, `<nav>`, `<main>`, `<article>`, `<aside>`, `<footer>`
  - 列表：`<ul>`, `<ol>`, `<li>`（不用 div 模拟）
  - 表格：`<table>`, `<th>`, `<td>`（不用 div 模拟）

## 💡 Suggestion

### A009 — 跳过导航链接
- **说明**: 长页面应提供"跳转到主要内容"链接
```jsx
<a href="#main-content" className="sr-only focus:not-sr-only">
  跳转到主要内容
</a>
<main id="main-content">
  {/* 主要内容 */}
</main>
```

### A010 — 状态变化通知
- **说明**: 动态内容变化应通过 ARIA live regions 通知辅助技术
```jsx
<div aria-live="polite" aria-atomic="true">
  {notificationMessage}
</div>
```

### A011 — 减少动画
- **说明**: 尊重用户 `prefers-reduced-motion` 设置
```css
@media (prefers-reduced-motion: reduce) {
  * {
    animation-duration: 0.01ms !important;
    transition-duration: 0.01ms !important;
  }
}
```
