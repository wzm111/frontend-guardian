# json-trailing-comma

检测 JSON 对象或数组末尾是否存在尾随逗号。

## 严重程度

`warning`

## 说明

JSON 标准（RFC 8259）不允许对象或数组最后一个元素后跟随逗号。虽然部分解析器（如 JavaScript 的 `JSON.parse`）会报错，但某些工具链可能只给出模糊的错误提示。本规则通过状态机扫描源码，跳过字符串和转义字符，定位真正的尾随逗号。

## 示例

### 错误

```json
{
  "name": "app",
  "version": "1.0",
}
```

```json
[
  1,
  2,
]
```

### 正确

```json
{
  "name": "app",
  "version": "1.0"
}
```

```json
[
  1,
  2
]
```

## 修复建议

移除对象或数组最后一个元素后的逗号。如果项目允许更宽松的语法，建议改用 `.jsonc` 或在构建工具中配置 JSONC 解析器。
