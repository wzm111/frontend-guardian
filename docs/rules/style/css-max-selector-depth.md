# css-max-selector-depth

限制 CSS 选择器的嵌套深度。

## 严重程度

`warning`

## 说明

过深的选择器会增加渲染计算开销、降低样式可复用性，并使代码难以阅读和维护。本规则检测选择器链深度超过 4 层的情况。深度按空格、`>`、`+`、`~` 等组合器拆分计算。

## 示例

### 错误

```css
.a .b .c .d .e {
  color: red;
}
```

### 正确

```css
.e {
  color: red;
}
```

## 修复建议

1. 使用更扁平的选择器。
2. 借助 BEM、SMACSS 或 Utility-first CSS 降低嵌套。
3. 对于 SCSS 嵌套，注意编译后会产生更深层级。
